# استوديو إنتاج المحتوى التعليمي الذكي 🎬✨
## تحديث: الصورة وبرومبت التحريك (Image-to-Video Sequence)

**تطبيق ويب متطور مدعوم بالذكاء الاصطناعي (AI) لتوليد نصوص إخراجية وسلاسل بصرية فائقة الدقة والترابط لإنشاء فيديوهات تعليمية وسينمائية للأطفال.**

---

### 🌟 ميزات نظام (الصورة وبرومبت التحريك):
1. **زوج متكامل لكل مشهد تعليمي (Paired Workflow):**
   - 🖼️ **STEP 1: IMAGE PROMPT (برومبت الصورة المرجعية الأولى):** كادر بداية ثلاثي الأبعاد مخصص لمولدات الصور (Midjourney / Recraft / DALL-E / Bing) يوضح المعلمة والشاشة واللافتة النيون.
   - 🎬 **STEP 2: IMAGE-TO-VIDEO MOTION PROMPT (برومبت التحريك بالفيديو):** أوامر حركة سينمائية نشطة لما بداخل الشاشة وتحريك الشفاه وحركة اليد المتزامنة لأدوات الفيديو (Flow / Hedra / Kling / Runway / Luma).
   - 🔗 **سلسلة الترابط والاستمرارية (Continuity Chain):** تسليم واستلام بصري دقيق يربط نهاية كل فيديو ببداية الفيديو التالي كشريط سينمائي متصل 100%.

2. **الشاشة الذكية العملاقة بدون نصوص (Pure Visual Storytelling):**
   - أعلى إطار الشاشة: لافتة نيون مضيئة تحمل النص الإنجليزي الحصري: `Sci.Rehab Elsibai`.
   - داخل الشاشة: رسومات ومجسمات كرتونية ثلاثية الأبعاد كيوت (أعضاء مبتسمة، تدفق دم، فلاتر تهتز، أسهم ملونة) بدون أي نصوص أو عناوين مشوهة.

3. **حركة الرحلة الحية داخل الشاشة (Active Journey Motion):**
   - الفيديو الأول يبدأ بمجسم شفاف كامل لجسم الإنسان مع زوم سينمائي ناعم نحو العضو المستهدف.
   - الفيديوهات اللاحقة تتضمن تدفقاً نشطاً مستمراً للسوائل والأعضاء والفلاتر طوال مدة الفيديو بدلاً من الصور المتجمدة.

4. **المعلمة وملابسها الثابتة:**
   - المعلمة رحاب تقف بجوار الشاشة مع ميكروفون احترافي وإطلالة تليفزيونية فخمة.
   - البدلة تتغير عشوائياً عند فتح درس جديد، وتظل مقفولة وثابتة 100% طوال استكمال صفحات نفس الدرس.
   - الكرتون يظهر على منصة المسابقات عند الحاجة للأسئلة فقط.

5. **منشئ مشهد الخاتمة والتوديع (Outro Video Generator 🎉):**
   - قسم مستقل لتوليد مشهد ختامي سينمائي للدرس بكبسة زر واحدة، مع استيراد تلقائي لآخر برومبت لتهنئة الأبطال وتوديعهم وتشويقهم للحلقة القادمة.
