# الاستوديو الاحترافي بين المعلم والشخصية الكرتونية 🎬🤖

**تطبيق ويب متطور مدعوم بالذكاء الاصطناعي (AI) لتوليد نصوص إخراجية (Video Prompts) احترافية.**

تم تصميم هذا النظام خصيصاً لإنشاء فيديوهات تعليمية تفاعلية بأسلوب (Podcast Studio) يجمع بين معلمة بشرية (مس رحاب) وشخصية كرتونية (طالب فضائي).

## الميزات الإخراجية والسينمائية (المثبتة في البرمجة):
- **ثبات الشخصيات (Absolute Character Consistency):** تم تثبيت وصف المعلمة (بليزر أرجواني) والكرتون (كائن أزرق بثلاث نقاط خضراء) برمجياً لضمان عدم تغير أشكالهم أبداً في أدوات الذكاء الاصطناعي (Vidu / Midjourney).
- **حركة الكاميرا الاحترافية:** زوايا مدروسة (Frontal View للمعلمة، و Over-The-Shoulder للكرتون) لضمان نجاح حركة الشفاه (Lip-Sync) بنسبة 100%.
- **الانتقال السينمائي المباشر (Seamless Transition):** منع السكوت التام في نهاية الفيديوهات، واستبداله بحركة إيمائية لتسليم الدور للشخصية الأخرى بسلاسة.
- **تفاعل الشاشة الذكية:** تزامن كامل بين ما تقوله الشخصيات وما يتم عرضه على الشاشة الذكية في الخلفية.
